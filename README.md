# Fund Analysis Pipeline - Quick Start

## What This Does
End-to-end fund analysis pipeline:
1. **Ingesting data** - Loads all fund position CSV files(from external-funds folder) into SQLite database with robust date parsing
2. **Reconciling prices** - Compares fund-reported prices with reference database prices using forward-fill logic for missing dates
3. **Calculating performance** - Identifies best-performing fund each month using rate of return (ROR = (end_MV - start_MV + realized_PL) / start_MV)

## Quick Start (2 commands)

```bash
cd solution
make install

source venv/bin/activate    # Activate venv
make run                    # Run the pipeline
```

## Output Files
- `output/price_reconciliation_report.csv` - 10,309 positions with price analysis
- `output/fund_performance_report.csv` - Monthly performance rankings
- `funds_analysis.db` - SQLite database with all processed data
